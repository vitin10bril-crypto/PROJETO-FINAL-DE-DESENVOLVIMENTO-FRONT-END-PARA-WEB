# SEP Vitin — Portfólio de Victhor Gabriel

Projeto acadêmico de desenvolvimento front-end para web, com HTML, CSS e JavaScript.

## Recursos

- Apresentação pessoal e trajetória.
- Matérias em estudo com filtros por tema.
- Tabuada interativa inspirada na atividade de programação.
- Layout responsivo e menu para celular.

## Organização

- `index.html` — página principal.
- `conteudo/` — páginas HTML complementares.
- `css/` — estilos.
- `js/` — interações.
- `imagens/` — imagens e ícone.

Abra `index.html` no navegador. Para publicar, configure GitHub Pages com a branch `main` e a pasta `/(root)`. Veja também `COMO_PUBLICAR.md`.
